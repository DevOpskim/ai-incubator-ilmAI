Goal
Deploy a full-stack AI study mentor (Ilm Agent) with OTP registration, eight MVP features, CI/CD pipeline, and production infrastructure on a single EC2 via Docker Compose.

Constraints & Preferences
Stack: Next.js 14 (frontend) + FastAPI Python 3.11 (backend) + PostgreSQL/pgvector (DB) + Docker Compose on single AWS EC2 (IP, region)
Container registry: Docker Hub
Deployment method: GitHub Actions → test → build & push images → SCP compose + Caddyfile → SSH docker compose pull && up -d
TLS: Caddy reverse proxy with auto Let's Encrypt on your-website.com
Auth: JWT stored in httponly cookie, forwarded through Next.js BFF proxy layer; registration gated by email OTP via Resend API
AI — chat: Multi-provider (OpenAI, Anthropic, Groq, DeepSeek, OpenRouter) via abstraction layer with per-request provider/model selector in chat UI
AI — default provider: Groq (llama-3.3-70b-versatile) via LLM_PROVIDER=groq in .env
AI — embeddings: Switchable via EMBEDDING_PROVIDER env var — local (fastembed, free, 384-dim all-MiniLM-L6-v2) or api (OpenRouter/OpenAI, 1536-dim)
Uploads: Persistent via bind mount ./uploads:/app/uploads on EC2 host; 10MB limit; extension check; delete endpoint removes file from disk
No local dev: edit code, commit, deploy to EC2
